01 / CONTEXTO E ENGENHARIA

O problema, as decisões
e o que aprendemos.

O SeguroGestor foi concebido para explorar como necessidades de uma operação de seguros podem ser traduzidas em entidades, relacionamentos, regras de negócio e telas de gestão.

REQUISITOS

Compreender o problema

A modelagem parte dos registros relevantes ao fluxo de seguros e sinistros e das regras que orientam o acompanhamento das informações.

DADOS

Modelo relacional

O modelo de dados e suas relações servem como base para consistência, rastreabilidade e consultas, conforme o escopo documentado no trabalho acadêmico.

EQUIPE

Construção colaborativa

O projeto contribuiu para praticar organização de requisitos, comunicação técnica, documentação e divisão de responsabilidades.

Estado e limites. O estudo de caso resume o contexto acadêmico conhecido. Funcionalidades, resultados e tecnologias específicas só devem ser adicionados após confirmar os artefatos finais do grupo. Os recursos e resultados apresentados não devem ser interpretados como certificação independente de produção.
